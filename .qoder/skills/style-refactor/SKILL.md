## Overview

本技能用于将选中文件的样式代码重构为符合项目样式策略的方案。根据样式属性数量决定最优样式实现方式。

## 样式策略规则

| 属性数量 | 条件 | 样式方案 |
|---------|------|---------|
| > 5 个 | 无条件 | **CSS Module**（`*.module.css`） |
| ≤ 5 个 | 无法用 UnoCSS 原子类实现 | **CSS Module** |
| ≤ 5 个 | 可用 UnoCSS 原子类实现 | **UnoCSS 原子类** |

UnoCSS 配置文件位于 `uno.config.ts`，原子类用法参考项目现有组件中的写法。

## 工作流

1. **读取选中文件**：获取用户选中或当前打开的文件内容，定位所有样式代码（inline style、CSS Module 文件、UnoCSS 原子类）
2. **统计样式属性**：逐个分析每个样式块/元素的样式属性数量
3. **判定样式方案**：根据样式策略规则表，为每个样式块选择最优方案：
   - 属性 > 5 → 迁移到 CSS Module
   - 属性 ≤ 5 且可用 UnoCSS 原子类 → 替换为 UnoCSS 原子类
   - 属性 ≤ 5 且无法用 UnoCSS → 保留 CSS Module
4. **执行重构**：
   - 将 inline style 迁移为 CSS Module 或 UnoCSS 原子类
   - 将过多属性的 UnoCSS 原子类组合迁移为 CSS Module
   - 合理归类属性到对应的 CSS Module 类名
   - 确保重构后功能表现不变，仅样式实现方式变更
5. **验证结果**：检查重构后代码无遗漏属性、无语法错误、类名无冲突
